# Aprender e Crescer

Repositório de estudos e exercícios organizado em pastas temáticas. A estrutura inclui materiais de backend e infraestrutura, com projetos e exemplos independentes.

## Organização

- `BACKEND/`: estudos e projetos de backend, incluindo exemplos com Express e APIs.
- `INFRAESTRUTURA/`: aulas e exemplos de ferramentas e práticas de infraestrutura e qualidade de código.

Cada subprojeto pode ter seu próprio `package.json`, dependências e comandos. Não há um comando único de execução confirmado para a raiz do repositório.

## Como executar um subprojeto

1. Entre na pasta do projeto que deseja estudar.
2. Leia o `README.md` local, se existir.
3. Confira o `package.json` dessa pasta para verificar as dependências e scripts disponíveis.
4. Quando o projeto usar npm, instale as dependências com `npm install` e execute somente um script que esteja declarado no respectivo `package.json`.

Os comandos e tecnologias variam entre os exercícios; não execute comandos de uma subpasta presumindo que valem para as demais.
